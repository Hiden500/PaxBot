# Безопасность

## Управление секретами

- **API Ключи (LLM)**: Ключи (Groq, Gemini, OpenAI) должны храниться только в `.env` файле, который добавлен в `.gitignore`. Никогда не коммитьте ключи в репозиторий.
- **Состояние Playwright**: Файл `auth/auth_state.json` содержит ваши cookies и токены сессии от игры Pax Historia. Этот файл также исключён из контроля версий. Не передавайте его третьим лицам.

## Риски и угрозы

- **Компрометация `auth_state.json`**: Злоумышленник может получить доступ к вашему аккаунту в Pax Historia.
- **Исчерпание лимитов LLM API**: Из-за бага или непредвиденного зацикливания агент может истратить баланс на OpenAI / Groq. Рекомендуется устанавливать жесткие лимиты биллинга в настройках провайдера (Hard limits).
- **Prompt Injection**: Теоретический вектор, если игра позволяет другим игрокам отправлять сообщения, которые агент спарсит и отправит в LLM. Модель может выполнить чужую команду.
