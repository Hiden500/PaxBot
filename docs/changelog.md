# Changelog

## [v3.7.1] — 2026-07-10: E2E-тестирование веб-интерфейса и конфигурация браузера

### Основные изменения

- **Вынесение конфигурации браузера**: Все жестко закодированные таймауты Playwright вынесены в централизованный `BROWSER_CONFIG` в `src/shared/config.ts`.
- **E2E-тестирование веб-интерфейса**: Создан сквозной E2E-тест `src/web/server.e2e.test.ts`, запускающий реальный Express/Socket.IO сервер и Playwright Chromium. Проверены загрузка страницы, переключение языков UI, обновление и сериализация настроек провайдера.

## [v3.7.0] — 2026-07-10: Локализация Web UI, логов и ошибок, устранение дублирования env

- **Интернационализация логов и ошибок (i18n)**:
  - Добавлена библиотека i18n с переводами логов когнитивного цикла на русский и английский языки.
  - Локализованы статусы и предупреждения в генераторе действий (`src/brain/action-generator.ts`), парсере ответов (`src/brain/response-parser.ts`), когнитивном цикле (`src/loop.ts`) и веб-сервере (`src/web/server.ts`).
  - Ошибки валидации LLM-ответов теперь выводятся на выбранном в конфигурации языке.

## [v3.6.3] — 2026-07-10: Переход к гибкой внешней политике ИИ и мягкой силе

### Основные изменения

- **Гибкая политика операций (FOREIGN OPERATIONS POLICY)**: Из системного промпта убрано жесткое требование обязательного военного завоевания (`military conquest`) при любых действиях на чужой территории.
- **Интеграция Мягкой Силы (Soft Power)**: В системный промпт ИИ добавлен блок поддержки невоенных инструментов влияния: мягкой силы, дипломатических союзов, культурно-идеологического влияния, экономического давления и диверсий.
- **Обновление в рантайме и тестах**: Обновлена резервная (fallback) копия промпта в исходном коде сборщика контекста (`src/brain/context-assembler.ts`) и адаптированы юнит-тесты (`context-assembler.test.ts`) под гибкие цели планирования.

## [v3.6.2] — 2026-07-10: Вынос системного промпта во внешний Markdown-файл

### Основные изменения

- **Динамический системный промпт**: Системный промпт LLM вынесен из исходного кода (`src/brain/context-assembler.ts`) в отдельный файл `src/brain/prompts/system.md`.
- **Замена плейсхолдеров**: Внедрена динамическая замена плейсхолдеров `{{WORLD_RULES}}` и `{{LANGUAGE}}` при сборке контекста для LLM.
- **Повышенная отказоустойчивость**: Реализован безопасный механизм fallback в случае отсутствия файла `system.md` на диске, обеспечивающий прохождение юнит-тестов и надежность во время работы.

## [v3.6.1] — 2026-07-08: Фиксы UI-взаимодействий, кодировки и логики промптов

### Основные изменения

- **Исправление работы панели действий (Action Panel)**: Добавлена поддержка русской локализации для кнопки «Действия» (`aria-label="Действия"`), а также внедрен 3-секундный таймаут на клик для быстрого обхода перекрывающих окон. Это решает проблему зависания бота на этапе открытия панели.
- **Исправление кракозябр (Mojibake) в JSON-ответах**: Метод `postData()` заменен на `postDataBuffer()?.toString("utf-8")` в `spy/capture.ts`. Теперь перехват тела запроса явно декодируется в UTF-8, предотвращая появление артефактов в кириллических текстах.
- **Аудит и улучшение LLM Промпта**:
  - Решена проблема с шаблонными переменными: восстановлен корректный синтаксис `${}` (ранее использовались обычные фигурные скобки `{}`, из-за чего в промпт попадали буквальные имена переменных вместо их значений).
  - Применен **Chain-of-Thought**: в формате вывода `reasoning` и `immediate_risks` перенесены в самое начало ответа LLM, чтобы заставить агента думать перед генерацией действий (ранее он сначала выдавал `actions`, а затем `reasoning`).
  - Добавлено строгое требование использовать язык, заданный в настройках, и опираться только на игровые сущности из Game State.
  - Исправлены синтаксические ошибки Typescript в `context-assembler.ts`, восстанавливающие корректную сборку.

## [v3.6] — 2026-07-07: Отложенная валидация, Husky-проверки и Repowise интеграция

### Основные изменения

- **Отложенная валидация API-ключей**: Убран принудительный краш `validateEnv()` при старте Web UI сервера. Интерфейс теперь успешно запускается без ключей. Проверка ключей срабатывает при непосредственном запуске когнитивного цикла бота.
- **Интеграция Husky Pre-Push и Pre-Commit**: Добавлены автоматические хуки Git: `pre-push` запускает проверку типов и тестов (`npm run typecheck && npm test`), `pre-commit` запускает `lint-staged`.
- **Автоматизация Repowise**: Добавлен хук `post-commit` для автоматического обновления базы данных repowise (`repowise update`). В `.gitignore` добавлены правила исключения кэшей `.repowise/*` с сохранением `config.yaml`.
- **Шаблон окружения**: Обновлен `.env.example`, добавлены переменные для `openaicompat` провайдера (`OPENAI_COMPATIBLE_API_KEY` и `OPENAI_COMPATIBLE_BASE_URL`).

## [v3.5] — 2026-07-06: Архитектурный рефакторинг, Веб-интерфейс и Постоянный профиль Chrome

### Основные изменения

- **Полноценный Web UI (Панель Лобби + Дашборд)**:
  - Разработан локальный Express + Socket.IO веб-сервер (`src/web/server.ts`), автоматически открывающийся в браузере при старте `npm start`.

- **Стабилизация Google Auth через постоянный профиль**:
  - `src/boot.ts` переписан на использование `chromium.launchPersistentContext` с указанием папки `auth/profile` и канала `"chrome"`. Google перестал сбрасывать авторизацию из-за смены отпечатков.
- **Декомпозиция God-файлов**:
  - `src/index.ts` разбит на `src/boot.ts` (запуск), `src/loop.ts` (цикл) и легкую точку входа.
  - `TUIDashboard` декомпозирован на хранилище данных `tui-state.ts` и `tui.ts`.
- **Управление приостановкой и полу-ручной режим**:
  - Добавлена кнопка «Приостановить / Возобновить» для «замораживания» выполнения хода.
  - Реализован переключатель «Полу-ручной режим» — бот совершает все расчеты и вставляет действия на ход, но ждет клика пользователя для перехода на следующий ход.
- **Интеграция**:
  - Провайдеры `OpenAI` и `Groq` унифицированы через `GenericOpenAIProvider`. Добавлен новый тип `openaicompat`.

- **Компиляция Markdown Кампаний**:
  - В Лобби интегрирован интерфейс выбора нескомпилированных шаблонов и кнопка «Скомпилировать кампанию из MD».
  - На сервере добавлено Socket.IO событие `setup:compile_campaign`, вызывающее `initializeCampaignFromMarkdown()` для преобразования MD-шаблона в JSON-кампанию и генерации стартовой стратегии через LLM.
- **Динамический список моделей (LLM_MODEL)**:
  - Добавлена функция `fetchModelsForProvider()`, запрашивающая список доступных моделей с API серверов OpenAI, Groq и Gemini (или возвращающая надежные дефолтные значения при отсутствии ключа/сети).
  - В Лобби добавлен выпадающий список для выбора модели ИИ, который сохраняет значение в переменную `LLM_MODEL` в `.env`.
- **Повышение надежности UI и локализации**:
  - Добавлено нажатие `Escape` и короткие таймауты (1.5 секунды) на клики в `dismissGamePopups()` для предотвращения бесконечных циклов зависания на невидимых или неактивных попапах.
  - Исправлено перекрытие системных логов отладочной JSON-панелью (обоим блокам выделена высота `h-[48%]`).
  - Реализовано переиспользование существующих вкладок Pax Historia в Playwright для предотвращения размножения вкладок при рестартах.
