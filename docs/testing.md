# Тестирование

Проект использует **Vitest** для написания unit- и интеграционных тестов.

## Запуск тестов

- Запуск всех тестов:
  ```bash
  npm test
  ```
- Тестирование конкретного модуля:
  ```bash
  npx vitest run src/campaign/
  ```

## Структура тестов

- `test/unit/` — Unit-тесты для парсеров, форматтеров, бизнес-логики без сети.
- `test/integration/` — Интеграционные тесты для проверки когнитивного цикла (с использованием моков для LLM).

## Покрытие (Coverage)

Для оценки покрытия используется команда:

```bash
npx vitest run --coverage
```

- Целевое покрытие для критичных модулей (`src/campaign`, `src/memory`, `src/brain`): > 80%.

## Ручное тестирование

Команда `npm run manual-test` позволяет протестировать генерацию промптов и парсинг ответов LLM без необходимости запускать Playwright.
